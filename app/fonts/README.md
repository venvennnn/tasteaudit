# Manrope

`manrope-latin-wght-normal.woff2` is the unmodified Latin variable font from
`@fontsource-variable/manrope` version 5.3.0 (weights 200–800).

Source: https://www.npmjs.com/package/@fontsource-variable/manrope/v/5.3.0

The font is distributed under the SIL Open Font License 1.1; see `OFL.txt`.
It is bundled here so production builds do not depend on Google Fonts responses.
